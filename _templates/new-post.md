# HOW TO ADD A BLOG POST
# 1. Copy this file into the _posts/ folder.
# 2. Rename it: YYYY-MM-DD-short-title.md  (e.g. 2026-11-12-my-first-post.md)
#    The date in the name is the publish date; the rest becomes the URL:
#    klarissapalacios.com/blog/my-first-post/
# 3. Fill in the lines below, write the post under the second "---", save.
# (These # lines are notes; you can delete them.)

title: "Your Post Title"
category: Lifestyle          # Lifestyle  or  PR & Comms  (spelled exactly like this)
cover: /assets/img/blog/your-photo.jpg   # put the photo in assets/img/blog/
cover_alt: A short description of the photo
description: One or two sentences shown on the Blog page card.
---

Write your post here. Leave a blank line between paragraphs.
